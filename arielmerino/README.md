# arielmerino.com

Sitio de **marca personal del Dr. Ariel Merino** — odontólogo estético, Puerto Madero.

## Qué es

Hoy es **una sola página**: presentación profesional con datos estructurados (Person schema, enlaces a Wikidata, Instagram, LinkedIn y YouTube).

## Para qué sirve

No es un segundo sitio de la clínica. Es el **hub de autoridad de la persona** que firma los casos clínicos de amesteticadental.com. En salud, Google evalúa que exista un profesional identificable y verificable detrás de la clínica (E-E-A-T), y este dominio es donde eso se sostiene.

Por eso el contenido que corresponde acá es el del profesional, no el de los tratamientos: formación, publicaciones, conferencias, prensa, reconocimientos.

## Estado

En producción, pero prácticamente vacío. Es el activo más desaprovechado del monorepo: una sola URL para posicionar a la persona que le da credibilidad a todo lo demás.

## Desarrollo

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
npm run build
```

Las reglas de copy de la marca están en el `AGENTS.md` de la raíz del monorepo y aplican también acá.
